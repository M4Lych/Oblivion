# Design system

Oblivion uses a night-stage palette: black `#090A12`, navy `#111827`, plum `#30233D`, surface `#1A1B28`, antique gold `#C7AD74`, silver `#C8C5D1`, and a contrast-adjusted teal action color. Compose draws a geometric player placeholder; no copyrighted character or logo art is bundled.

The dashboard prioritizes a prominent character stage, profile context, compact service status, and large Play action. Portrait uses stacked cards and bottom navigation; wide layouts place character and launch controls in two columns. Secondary screens use consistent surfaces, labels, and explicit configured/unavailable states.

The skin screen currently samples a selected PNG to tint the launcher placeholder. It does not render the full Minecraft UV model or set a skin in the game. All important states use readable text as well as color.
